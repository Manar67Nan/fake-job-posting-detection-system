# Fake Job Posting Detection System (FJPD)
Project Preview
![FJPD Homepage](homepage.png)



Live Demo: https://fakejobpostingdetector.com/

FJPD is a machine learning-powered web application that analyzes job postings and classifies them as potentially real or fraudulent using Natural Language Processing (NLP) and text classification.

## Overview
FJPD is a machine learning-powered web application designed to detect potentially fraudulent job postings using Natural Language Processing (NLP) and text classification techniques.

The system analyzes job posting information and predicts whether a job advertisement is real or fake.

## Key Features
- Fake job posting classification using machine learning.
- Natural Language Processing (NLP) for text analysis.
- Web-based user interface for analyzing job postings.
- Backend API built with FastAPI.
- Admin dashboard for viewing records and statistics.
- Feedback functionality for user responses.

## Technologies Used
- Python
- FastAPI
- Machine Learning
- Natural Language Processing (NLP)
- HTML, CSS, and JavaScript
- SQLite
- TF-IDF Vectorization
- Text Classification

## Project Structure
- `SOURCE/backend/` — Backend application, API routes, and machine learning components.
- `SOURCE/frontend/` — Frontend interface.
- `DATABASE/` — Project data files.
- `DOCUMENTS/` — Project documentation.
- `PREREQUISITES/` — Required dependencies.
- `SETUP/` — Setup instructions.

## Project Purpose
The goal of this project is to explore how machine learning and NLP can help identify suspicious job advertisements and support safer online job searching.

## Academic Project
Developed as a senior project to demonstrate practical skills in machine learning, text processing, and web application development.
